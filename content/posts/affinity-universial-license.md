2022 年，我尝试通过阿根廷区 Microsoft Store 购买 **Affinity 通用许可证**。折算后的商品价格约 8 美元，加上代付成本，实际花费大约在 13–15 美元。

这篇留下当时的操作过程和支付经历。文中的价格、活动和购买方式都属于 **2022 年的历史记录**。

## 买的是什么

当时的通用许可证，可以在支持的平台上激活 Affinity 的三款产品：**Photo、Designer 和 Publisher**。

产品信息入口留在这里：[Affinity 官网](https://affinity.serif.com/en-us/)。

## 当时的价格

| 项目 | 当时记录 |
| --- | --- |
| 商品标价 | 1,439.40 阿根廷比索（ARS） |
| 折合人民币 | 约 57 元 |
| 折合美元 | 约 8 美元 |
| 包含代付的实际成本 | 约 13–15 美元 |

## 在 Windows 上发起购买

我当时的操作顺序是：

1. 准备一台能正常使用 **Microsoft Store** 的 Windows 电脑。
2. 在系统设置中，把国家或地区切换为**阿根廷**。
3. 通过 Microsoft Store 下载 **Affinity Photo 2**。
4. 打开软件，在购买提示中进入付款流程。

一开始我以为还需要调整 IP，后来这次实际操作中发现，关键是系统地区设置。

## 最费时间的是付款

自己的信用卡付款没有成功。按当时的尝试和查到的信息，支付方式很可能是主要限制。

我也看过淘宝代购，但活动开始约一个月后，不少商家已经把通行证直接上架，常见报价在 **158–180 元**，明显高于当时的地区价格。礼品卡和虚拟卡的路也没走通：我没有找到可用的阿根廷礼品卡方案，尝试开虚拟卡时又遇到了当地手机号和身份证件要求。

最后，我在 **Upwork** 发布需求并邀请了几位当地用户，其中一位接受了邀请。事先沟通清楚商品约 **1,440 ARS** 的成本，以及 **15 美元**的总付款安排后，对方大约花了十来分钟就完成了购买。

当时采用的是让对方登录账号代购的方式。购买后，对方移除了自己的付款方式，我也移除了对方的设备。这是那次交易的经过。
