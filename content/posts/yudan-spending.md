知道鱼蛋要来的那一刻起，我就总想为她做点什么。

最初只是随手在手机备忘录里记几笔：今天买了云柔巾，明天又添了一件小东西。记着记着，又觉得只留下花了多少钱，好像少了些什么。那些成长中的小变化，也值得有个地方好好放着。

于是，我做了这个小项目：**鱼蛋花费**。一半是账本，一半是成长日志。

## 给我们的小家，留一个记录的地方

记账软件很多，写博客的平台也不少。我想做一个适合自己随手记录的小站：买了东西能很快记一笔，有了想写的小故事也能放上去。

目前就围绕这两件事来做，功能够用，维护起来也轻松。

## 鱼蛋小账本：几秒钟，记好一笔

给宝宝买东西，经常是想到什么就添什么。如果每次记账都得打开 App、找分类、填金额，很容易把这件事往后拖。

所以账本最在意两点：**录入快，查看清楚**。

- **一句话记账**：支持简单的自然语言输入，比如「午饭 35」。
- **Telegram 随手记**：直接给 Bot 发消息，不用专门打开记账页面。
- **分类与关键词筛选**：想回看某类支出时，可以按分类或关键词查找。
- **集中保存记录**：账本数据存放在 Supabase 中。

现在买完东西，我习惯给机器人发一句「奶粉 280」，几秒钟就记好了。

## 成长日志：把小变化也记下来

除了开销，我更想留下鱼蛋成长中的点滴。

日志直接用 Markdown 写，放在 `content/blog/` 目录里，静态生成后就能展示。不需要为写一篇小记录再去登录后台，也不用单独维护内容数据库。

代码高亮也保留了。以后说不定还可以教鱼蛋写代码，想到这里就觉得很有意思。

等她会笑、会翻身，再到学会更多新本领，都可以慢慢记在这里。等她长大，再一起回头看。

## 用熟悉的技术，把小站搭起来

作为一个喜欢写代码的爸爸，我选了自己熟悉的一套工具：

| 部分 | 使用的技术 |
| --- | --- |
| 框架 | Next.js 16 App Router |
| 语言 | TypeScript |
| 界面 | Tailwind CSS 4、Radix UI |
| 账本数据 | Supabase PostgreSQL |
| 日志内容 | Markdown、react-markdown |
| 记账 Bot | Telegram Webhook |

账本需要保存结构化数据，日志则继续用文件管理。这样分工，已经能满足这个小项目目前的需要。

## 和鱼蛋一起，慢慢成长

做这个项目的过程，也像是在学习怎么当爸爸。

以前写代码，总容易想着把功能做得大而全。现在更在意它有没有解决眼前的小问题：能不能顺手记账，能不能让我愿意持续写下去，能不能让以后多一些可以翻看的回忆。

后面也许会加上每月支出图表，或者给日志增加草稿功能。不过不急，慢慢做就好。

代码会继续放在 GitHub，也欢迎通过 Issue 交流写代码和育儿的心得。

鱼蛋，这是爸爸给你做的第一个小项目。欢迎你来到这个世界。❤️
